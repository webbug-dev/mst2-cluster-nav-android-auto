# Roadmap

What the mod already does is in the [README](../README.md). This page lists only what is ahead.

- **Android Auto**: the cluster map in decode mode and the native arrows are verified in a car
  ([ANDROID-AUTO.md](ANDROID-AUTO.md), 2026-11-10). Ahead: a day/night theme switch for the
  phone's cluster map (only the dark theme is requested today), cover art.
- **Not possible from the Android Auto protocol**: a speed limit on the cluster display and a
  steering-wheel zoom of the phone's cluster map. Both exist for CarPlay only.
- **Steering-wheel zoom** of the CarPlay cluster map.
- **CarPlay media on the cluster**: track, artist and cover art in the cluster's media view.
- **CarPlay calls on the cluster**: call state and caller in the cluster's phone view.
- **Destination handoff**: a CarPlay destination into the built-in navigation (the stock iAP2
  driver supports it, off on this unit).
- **CarPlay sound vs Bluetooth**: compare the CarPlay audio path with A2DP and the DSP presets.
